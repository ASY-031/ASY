# 웹전시: 우리, 어디서 본 적 있나요?

정적 웹 파일만으로 구성된 GitHub Pages용 웹전시입니다. 빌드나 패키지 설치가 필요하지 않습니다.

## GitHub Pages에 게시하기

1. GitHub에서 새 저장소를 만들고 이 폴더 안의 파일을 저장소 최상위에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 게시할 브랜치(예: `main`)와 폴더(`/ (root)`)를 선택하고 저장합니다.
5. Pages가 게시되면 같은 설정 화면의 링크로 전시를 확인합니다.

`index.html`과 네 개의 PNG 이미지는 같은 폴더에 있어야 합니다. 이미지 링크는 상대 경로로 연결되어 있습니다.
